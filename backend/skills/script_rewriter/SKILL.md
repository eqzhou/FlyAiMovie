# 剧本改写指南

## 原则
1. 保留核心情节、人物关系与关键冲突，不发明与原意冲突的新结局。
2. 叙述转为可拍摄画面：动作、表情、环境变化优先于内心独白。
3. 以对话驱动推进；单场目标时长约 30-60 秒，信息密度高、冗余低。
4. 不写镜头语言（景别/运镜/机位留给分镜阶段）。
5. 保持角色称谓一致；新角色首次出场写清身份线索。

## 格式
```
## S01 | 内景 · 咖啡厅 | 黄昏

动作与环境描写...

小红：（微笑）台词
小明：回应台词
```

## 场景头规则
- `S` + 两位序号，连续递增
- 内景/外景 · 地点 | 时间段（清晨/白天/黄昏/夜晚等）
- 一场一事：地点或时间明显变化时开新场景

## 对白规则
- `角色名：（可选状态）台词`
- 状态词简短（愤怒/压低声音/停顿）
- 旁白仅在必要时使用，避免长篇解说

## 步骤
1. `read_episode_script` 读取当前集输入
2. 改写为格式化剧本
3. `save_script` 写回；确认场景头与对白格式完整
