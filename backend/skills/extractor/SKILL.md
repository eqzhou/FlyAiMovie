# 角色与场景提取

## 角色字段
- 姓名：剧本中稳定称谓
- 定位：主角/配角/功能角色
- 外貌：300-500 字可视化描写（年龄感、发型、服装、标志物）
- 性格：3-6 个可表演特质
- 背景：与本集相关的简短经历

## 场景字段
- 地点：可复用地点名
- 时间：时间段或具体时段
- 氛围：光线、天气、情绪
- 英文画面提示词：纯背景，不含人物与字幕

## 去重
- 角色：同名/明显别名合并；保留更完整外貌与性格
- 场景：地点 + 时间段精确匹配合并
- 不把道具当角色；不把瞬时过场当独立场景

## 步骤
`read_script_for_extraction` → `read_existing_*` → `save_dedup_characters` / `save_dedup_scenes`

## 质量检查
- 每个有台词或关键动作的角色均有记录
- 每个场景头对应一个场景
- 外貌描述足够支撑形象生成
