# Shot / grid panel prompt scaffold

Template:
`[shot size], [camera angle], [subject action], [location], [lighting], cinematic still, consistent art style, no text, no watermark`

Grid rules:
- Exactly N panels; each panel has one clear beat.
- Keep character wardrobe continuity across panels.
- first_frame focuses on opening pose; first_last pairs open/close; multi_ref keeps shared style tokens.
