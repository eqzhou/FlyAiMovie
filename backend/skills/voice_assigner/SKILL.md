# 音色分配

## 匹配优先级
1. 性别匹配
2. 年龄感匹配（少年/青年/中年/老年）
3. 性格与声线气质匹配（沉稳/明亮/沙哑/清冷等）
4. 主角优先高辨识度音色，配角避免与主角撞声

## 约束
- 只从可用音色列表分配，不发明 voice_id
- 同一角色全集一致；已有有效音色时不要无故更换
- 群演可共用相近音色，但主要角色必须区分

## 步骤
`list_voices` → `get_characters` → 对每个缺音色角色 `assign_voice`

## 输出
- 每个需配音角色都有 voice_id
- 分配理由内化在选择中，不写入无用字段
